🔗 How to sync with your team

This calendar saves data locally in your browser. To share events and tasks with your EXCO members, use the Backup → Share → Restore workflow below.

⚡ Faster one-click options
📆 Download .ics — exports every event as one standard calendar file members can import into Google / Apple / Outlook Calendar in a single step.
🌍 Publish view-only copy — downloads a read-only HTML version of this calendar with all events baked in. Drop it in the Telegram group; members just open it (no restore needed, and they can't edit anything).
Step 1 — You (the updater) backup
Click 💾 Backup events & tasks in the footer. A file named NUSSemiCon_Events_Backup_YYYY-MM-DD.json will download. This includes all events and to-do tasks.
Step 2 — Share the file with your team
Send the .json file to your EXCO via:
  • Telegram — tap 📎 → File (not photo)
  • Google Drive / SharePoint — drop into a shared EXCO folder
  • WhatsApp — tap 📎 → Document
  • Email — attach the .json file
Step 3 — Members restore on their device
Each member opens the calendar HTML file in their browser, clicks 📂 Restore from backup in the footer, selects the shared .json file, and confirms. The calendar updates instantly with all events and tasks.
💡 Recommended EXCO workflow
One person owns the master copy (e.g. President or Vice President). After every update — new event added, task edited, status changed — they backup and share the file to a pinned Telegram message or shared Google Drive folder.

Members restore whenever they need the latest view. Tip: name your backups with a note like Calendar_Sem1_Week3.json so it's easy to track which is the most recent.
